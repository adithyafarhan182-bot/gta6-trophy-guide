LEONIDA LEGEND — the offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, an 8-stage roadmap to the platinum, the one missable trophy flagged, and a checklist saved in the browser with export and import, filters and a spoiler setting. No Rockstar artwork, no network — it runs from its own files.

## Run it

```sh
node serve.ts
```
